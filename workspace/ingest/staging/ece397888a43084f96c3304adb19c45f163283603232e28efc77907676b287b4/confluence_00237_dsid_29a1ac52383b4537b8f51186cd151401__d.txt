Deployable Value Sprint Playbook and Technical Evidence

Summary
-------
This playbook guides a cross-functional value sprint that yields a deployable pilot of Redwood Inference in 6 weeks for midmarket and SMB product teams. The goal is to produce a working integration, measurable economic impact (latency and cost), and security evidence that satisfies a technical buyer and their CISO. Use this playbook to accelerate deal qualification, reduce risk, and shorten time from proof-of-concept to first production route.

One-line value proposition
-------------------------
Run production-grade LLM inference with predictable latency and transparent unit economics so product teams can ship conversational features without building and operating a custom serving stack.

When to use this playbook
-------------------------
- Prospects with a defined product use case and sample data (chat, summarization, or embeddings).
- Platform or product engineers willing to run a 6-week pilot.
- Security/compliance gate that requires evidence (audit logging, data residency, KMS).

Sprint overview (6 weeks)
------------------------
1. Week 0: Intake & sizing (sales + solutions)
   - Outcome: pilot statement of work (SOW) with success metrics and access plan.
   - Inputs: sample traffic shape, latency target, data sensitivity class, pilot duration.
2. Week 1: Environment & baseline
   - Outcome: baseline measurements (existing latency/cost) and minimal integration plan.
   - Tasks: provide API keys, create test dataset, configure sandbox model.
3. Weeks 2–3: Implementation & validation
   - Outcome: integrated endpoint and initial functional tests.
   - Tasks: SDK or REST integration, streaming config, fallback routing test.
4. Week 4: Performance tuning and observability
   - Outcome: configured batching and caching, dashboards for cost/latency.
   - Tasks: enable token-level cost breakdown, tracing hooks, add eval prompts.
5. Week 5: Security evidence & governance
   - Outcome: evidence pack (audit logs, KMS usage, network controls).
   - Tasks: collect logs, confirm RBAC, review data retention policy.
6. Week 6: Closure & handoff
   - Outcome: decision (scale, renew, or sunset) and cutover plan if progressing.
   - Deliverables: pilot report, recommended capacity profile, pricing scenario.

Positioning and messaging by buyer persona
-----------------------------------------
- Platform Engineer: emphasize unified runtime, predictable throughput, autoscaling controls, and clear batching knobs.
- Product Manager: emphasize time-to-market, measurable improvement in user engagement, and quick rollback paths.
- CISO/Security: emphasize data residency options, KMS/HSM integration, audit logging, and private deployment choices.
- Finance/Procurement: emphasize unit economics, pilot pricing, and reserved capacity discounts.

Competitive brief: head-to-head narrative
---------------------------------------
Key differentiators to lead with:
- Production-first controls: per-route SLOs, automatic fallback to lower-cost model variants, and token-level cost breakdowns for chargeback.
- Unified deployments: same API and rollout policies across hosted, dedicated, and private (VPC/on-prem) — minimizes migration risk.
- Cost operations: built-in batching/caching suggestions with modeled cost impact and quantization guidance.

Common competitor weaknesses to exploit:
- Simpler APIs but opaque performance: many providers do not expose token-level economics or KV cache behavior.
- Limited private deployment: some vendors only offer hosted endpoints or complicated on-prem toolchains.
- Poor fallback behavior: many stacks lack automatic model variant routing and graceful degradation under pressure.

Pricing guidance and pilot scenarios
----------------------------------
Pricing principles
- Start simple for pilots: single blended per-token rate + pilot support fee.
- Show modeled cost delta: compare current infra or competitor per-token costs vs Redwood with batching enabled.

Three pilot pricing scenarios (examples)
1) Rapid evaluation (2–4 weeks)
   - Fee: $2,500 flat credit + usage at $0.0008 per input/output token.
   - Support: email + one solutions call.
2) Standard deployable pilot (6 weeks)
   - Fee: $15,000 pilot package (includes 4 support hours/week).
   - Commit: optional $10k reserved credit at a discounted rate if moving to Dedicated.
3) Enterprise sandbox (6–12 weeks)
   - Fee: $45,000 (onboarding, security review coordination, 24/7 support for the pilot window).
   - Add-ons: private control plane license, enhanced retention for observability.

Security FAQ for prospects (short answers for field use)
------------------------------------------------------
Q: How does Redwood protect customer data in hosted mode?
A: Customer data is isolated per tenant, encrypted at rest and in transit, and can be configured to use customer-managed keys (KMS). Audit logs are retained per the agreed retention period.

Q: Can we run Redwood inside our VPC or on-prem?
A: Yes. Redwood Private supports a customer-managed control plane and on-prem packaging for air-gapped environments. We provide a deployment checklist and optional engineering assistance.

Q: What authentication and RBAC options exist?
A: Granular API keys, OAuth integrations for console access, and role-based access controls for team-level permissions. Integrates with SSO via SAML/OIDC.

Q: How are logs and PII handled?
A: Logs are redacted by default for known PII patterns; customers can opt into additional redaction rules. Audit logs are separate from payload storage and can be retained or forwarded to the customer's SIEM.

Q: What evidence do you provide for a security review?
A: Typical package includes architecture diagram, KMS integration proof, SOC/ISO certifications (where available), sample audit logs, network diagram, and a runbook for incident response tailored to the pilot.

Rollout checklist (minimum viable deliverables for a pilot)
---------------------------------------------------------

- Sample dataset and test harness (postman/pytest).
- Baseline latency and cost report.

- Security evidence pack prepared for CISO review.
- Pilot closeout report template populated with results and recommendation.
