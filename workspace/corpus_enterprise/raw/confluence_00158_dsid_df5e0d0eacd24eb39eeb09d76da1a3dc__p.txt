Platform inference economics and closure toolkit — GTM sales kit

One-paragraph summary: This sales toolkit helps AEs, SEs and product-focused buyers evaluate and close deals for inference deployment. It packages positioning, a competitive evidence summary, three executable pilot scenarios with pricing heuristics, a decision checklist, a short security FAQ, and two bite-size case vignettes. Use as a single-slide or email handoff in technical discovery.

Text summary of competitive matrix: Dimensions compared include deployment modes, unit economics controls, operational SLO tooling, security posture, time to production, and buyer win angle. Scenario A — Quick evaluation pilot (30 days): Hosted API, 5k monthly requests, trial credit first 50k tokens, estimated pay-as-you-go $150–$400 depending on model; win criteria: <200ms p50, audit log export.
Scenario B — Pre-production Dedicated pilot (90 days): 1 Dedicated slot (H100 equivalent), autoscaling 1x baseline 2x burst, example reserved slot fee $10,000/mo + token egress; win criteria: p95 <=1.5x SLA baseline, cost within quote, rollback tested.
Scenario C — Private regulated POC (6 months): Private control plane or on-prem, customer-managed keys, platform license + professional services $200k–$500k; win criteria: security signoff, pen test pass, full-load performance validation.
Pre-engagement checklist: 1) workload profile (tokens/request, concurrency, seasonality), 2) security needs (residency, KMS, DPA), 3) success criteria and rollback triggers. Pilot activation script (1–3 business days): 1) create trial/Dedicated slot and scoped API keys, 2) deliver SDK quickstart and logging samples, 3) enable dashboards and alerts (p95 SLA and token-cost thresholds), 4) run synthetic traffic and KV cache validation, 5) run <1% real-traffic canary and evaluate quick-evals, 6) test rollback to quantized variant and verify continuity. Post-pilot: deliver 1-page exec report with cost per 1k tokens, p95 latency, quality regression delta.
Q: How is customer data isolated in Hosted mode? A: Logical isolation by project and customer ID; recommend Dedicated/Private for regulated data.
Q: Which KMS/HSM integrations are supported? A: AWS KMS, GCP KMS, Azure Key Vault, optional Cloud EKM and customer HSM appliances for Private.
Q: Can we export raw audit logs and traces? A: Yes — logs/traces/cost events can be exported to S3/GCS/Azure Blob or SIEM via syslog/EventHub.
Q: Is encrypted inference (BYOK for model weights) supported? A: Supported in Private via EKM-managed decryption and secure enclave workflows; hosted uses provider-managed model keys.
Q: Certifications and pen tests? A: SOC2 Type II; ISO 27001 in targeted regions; annual third-party pen-test reports available under NDA.
Q: Patch and CVE management for Private? A: Scheduled patch cadence, security bulletins, offline signed artifact bundles and migration/rollback instructions for air-gapped customers.
